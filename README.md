 Task 2: Data Visualization and Storytelling

 Objective
The objective of this task is to create simple data visualizations and identify useful business insights from sales data.

Tools Used
- Python
- Pydroid 3
- Python Data Structures

Dataset
A sample sales dataset containing three categories:

- Technology
- Furniture
- Office Supplies

The dataset includes:
- Sales
- Profit
 
Data Analysis
The program calculates:

- Total Sales
- Total Profit
- Sales for each category
- Profit for each category

Key Insights
1. Technology has the highest sales.
2. Furniture has medium sales.
3. Office Supplies has lower sales.
4. Technology has the highest profit.

 How to Run
1. Open Pydroid 3.
2. Copy the Python code into a new file.
3. Save the file.
4. Press the Run button.
5. The sales and profit details will be displayed in the output.
